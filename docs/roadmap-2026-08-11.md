# 실행 로드맵 — 2026-08-11 (마스터)

네 감사를 하나의 실행 순서로 재편성한 문서. 상세 "무엇을 고치는가"는 아래 세 문서에 있고, 이건 **"무엇을 언제,
무엇 다음에"**만 다룬다.

- `docs/regression-test-2026-08-10.md` — 라이브 재현 71판정 (P0 3건의 출처)
- `docs/fix-plan-2026-08-11.md` — GPT 23건 검증 + 08-11 피드백 (W1~W11 상세)
- `docs/capability-integrity-2026-08-11.md` — 기능 경로 무결성 (W11의 근거)

**W 번호는 그대로 둔다**(상세 문서와의 참조 유지). 이 문서는 그 W들을 **뿌리·의존성 기준으로 재배열**한 것이다.
아직 코드는 수정하지 않았다.

---

## 재편성 원리

1. **뿌리로 묶는다, 증상으로 나열하지 않는다.** 감사 결과 여러 증상이 같은 코드 뿌리를 공유한다 — 뿌리 하나를
   고치면 티켓 여러 개가 닫힌다. (예: "죽은 출력 커밋 · 수동 Recompute 강요 · 43.6% 빈출력"은 전부 W2 한 뿌리.)
2. **우선순위 = (사용자 체감 빈도 × 안전 영향), 단 의존성이 게이트한다.** 아무리 급해도 선행 조건이 안 되면 뒤로.
3. **재발 방지(W11)는 별도 대공사가 아니라 각 수정에 심는 규율.** 뿌리를 고칠 때 그 자리에 해당 커버리지 테스트를 함께 넣는다.

## 의존성 그래프 (핵심만)

```
W8(하네스) ─┬─▶ W1(턴 종료) ─┬─▶ W4(카드 배관) ─▶ W9(ask 규범)
            │                └─(ComposeAskBlock)─┘
            └─▶ (W1·W4 검증)

W2-a(probe) ─▶ W2(죽은출력)   [W11-g = W2의 처방]
W3-a(probe) ─▶ W3(GH 모달)

W5 · W6 · W7-a · W7-b · W10 : 독립 (아무 데나 슬롯)
W11-a/c/d/e : 각 뿌리 수정에 심거나 Phase 3에 배치
```

**임계 경로(critical path)**: `W8 → W1 → W4 → W9`. 이 사슬이 카드 UX 전체를 지배하고, 순서를 어기면
안전 문제가 증폭된다 — 특히 **W9(모델이 ask_user를 더 부르게)를 W1+W4(ask 답변이 안전하게 도달) 전에 하면
지금의 P0(ask 답변→세션 사망)를 더 자주 터뜨린다.** 그래서 W9는 반드시 W1·W4 뒤.

## 단계별 실행

### Phase 0 — 착수 준비 (즉시, 병렬)

P0 중 둘(W2·W3)이 조사 선행을 요구하므로 먼저 깐다. W1은 조사 불필요라 여기서 바로 시작 가능.

- **W8 하네스 스캐폴드** — 카드 엔드포인트 WebApplicationFactory(approval/ask/goal PUT·DELETE). W1·W4의 검증 기반.
- **probe 배치(라이브 1세션, example/ 파일 + verify-2026-08-10 하네스 재사용)**:
  - **W2-a** — 어댑터의 execute 후 solve 완결 경로 확정: volatile data가 왜 안 채워지는가(ExpireSolution/CollectData/upstream 재수집 순서). 신규 슬라이더 출력조차 0인 기전.
  - **W3-a** — 어떤 컴포넌트 타입(GH Button 등)이 InstantiateT 모달을 유발하는가 + `GH_Param<T>.TypeName` 접근 지점 전수.
- **산출**: W2·W3 구현이 조사 결과에 앵커되도록. probe 없이 손대면 오진 위험(R3의 "무거운 solve" 오진이 그 예).

## 권장 첫 수 (구체적 시작점)

**W8 하네스 + W1을 함께 착수하면서 W2-a·W3-a probe를 병렬로 돌린다.**
- 이유: W1은 조사 불필요·순수 오케스트레이터 로직이라 즉시 가능하고, 임계 경로의 뿌리이며, "모든 카드 턴이
  빨간 오류로 보이는" 상시 신뢰 훼손 버그를 없앤다. W8은 그 검증 기반이자 W4의 선행. 그동안 probe가 끝나면
  W2·W3이 조사에 앵커된 채 이어진다.
- 첫 PR 후보: `W1 + W8(카드 턴 골든 시나리오 테스트) + W11-b` 한 묶음.
